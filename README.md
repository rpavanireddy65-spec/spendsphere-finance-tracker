# 💰 SpendSphere - Personal Finance Tracker

SpendSphere is an interactive personal finance management web application designed to help users track their income and expenses, understand their spending habits, monitor budgets, and visualize financial data through interactive charts and reports.

The project provides a clean, modern, and responsive dashboard that makes personal finance tracking simple and engaging.

---

## ✨ Features

- 💰 Track income and expenses
- 📊 Interactive financial dashboard
- 📈 Income vs. expense visualization
- 🍩 Expense category breakdown
- 📉 Monthly spending analysis
- 🎯 Monthly budget tracking
- 💡 Automatic spending insights
- 🔎 Search transactions
- 🗑️ Delete transactions
- 📄 Financial reports
- ⬇️ Export transactions as CSV
- 🌙 Dark mode
- 💾 Browser data storage using LocalStorage
- 📱 Responsive design for mobile and desktop
- ⚡ No backend required

---

## 🖥️ Dashboard

SpendSphere provides a dashboard containing:

- Total Income
- Total Expenses
- Current Balance
- Savings Rate
- Monthly Budget
- Recent Transactions
- Spending Insights
- Interactive Charts

---

## 📊 Analytics

The analytics section helps users understand their financial behavior through:

- Income vs. Expense chart
- Monthly expense trends
- Category-wise spending
- Highest expense
- Average expense
- Total transaction count
- Top spending category

---

## 🧾 Reports

Users can view a complete financial report containing:

| Date | Description | Category | Type | Amount |
|------|-------------|----------|------|--------|
| 2026-09-01 | Salary | Salary | Income | ₹25000 |
| 2026-09-02 | Groceries | Food | Expense | ₹1500 |
| 2026-09-04 | Bus Travel | Transport | Expense | ₹500 |

The report can also be exported as a CSV file.

---

## 🧠 Smart Spending Insight

SpendSphere automatically analyzes the entered transactions and identifies the category where the user spends the most.

For example:

> Food is your highest spending category at ₹4,500, which is 32% of your total expenses.

This gives users a quick understanding of their spending behavior.
